## Overview

**IUCampus** is an Android app (Jetpack Compose) that provides a simple campus-style experience:
- Browse available courses and view details
- Explore dining locations on a map
- Create and view gatherings
- Basic login/profile flow (local session)

2. Let Gradle sync finish.
3. Run the `app` configuration on an emulator or a physical device.
